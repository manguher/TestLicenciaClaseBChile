# Test Teórico Licencia Clase B Chile

> Simulador gratuito del examen teórico para obtener la licencia de conducir clase B en Chile.

## 📝 Descripción

Esta aplicación web permite a los usuarios practicar para el examen teórico de la licencia de conducir clase B en Chile. El test simula el formato oficial del examen, seleccionando 35 preguntas aleatorias de un banco de preguntas completo y actualizado.

### Características

- ✅ Selección aleatoria de 35 preguntas en cada intento
- ✅ Preguntas con imágenes de señalética y situaciones de tránsito
- ✅ Soporte para preguntas de selección única y múltiple
- ✅ Navegación intuitiva entre preguntas
- ✅ Revisión completa de respuestas al finalizar
- ✅ Puntaje final con indicación de aprobación (mínimo 30 correctas)
- ✅ Interfaz responsive para dispositivos móviles y escritorio
- ✅ 100% gratuito y de código abierto

## 🚀 Instalación Local

```bash
# Clonar el repositorio
git clone https://github.com/TU_USUARIO/test-licencia-b-chile.git

# Navegar al directorio del proyecto
cd test-licencia-b-chile

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
```

## 💻 Tecnologías

- Vue.js 3 (Composition API)
- Tailwind CSS
- JavaScript ES6+
